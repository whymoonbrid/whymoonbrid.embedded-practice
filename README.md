# embedded-practice

C 语言与 STM32 的学习记录。语法练习、外设驱动、接线图，写坏了也留着。

## 目录

| 目录 | 内容 |
| --- | --- |
| `c/` | C 语言练习：语法、指针、数据结构 |
| `stm32/` | STM32 项目：每个小项目一个子目录，放代码、接线说明、运行结果 |

## 约定

- 每个 STM32 项目目录里放一份自己的 README，写清用了哪些外设、引脚怎么接、跑起来是什么现象。
- Keil / CubeIDE 的编译输出不进仓库，忽略规则见 `.gitignore`。
- 已有作品陆续整理搬进来，整理好一个提交一个。

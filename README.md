# whymoonbrid.embedded-practice

技术练习记录：机械成图、C 语言、STM32，外加暂时占位的几个方向。写坏了也留着。

## 目录

| 目录 | 内容 | 状态 |
| --- | --- | --- |
| `solidworks/` | 零件、装配体、工程图，制图规范与 BOM | 主线，进行中 |
| `c/` | C 语言练习：语法、指针、结构体、数据结构 | 进行中 |
| `stm32/` | STM32 项目：GPIO、定时器、串口、ADC、I2C/SPI | 进行中 |
| `pcb/` | 原理图、布局布线、打样闭环 | 大二开始 |
| `python/` | Python | 暂缓 |
| `plc/` | PLC | 暂缓 |
| `vision/` | 机器视觉 | 暂缓 |
| `data-analysis/` | 数据分析 | 暂缓 |

暂缓的目录只占位，不放学习计划；主动开始学的时候再往里填。

## 约定

- 每个项目目录里放一份自己的 README，写清用了什么、怎么复现、跑起来是什么现象；STM32 写清外设和引脚接法。
- Keil / CubeIDE 的编译输出、SolidWorks 的临时文件不进仓库，忽略规则见 `.gitignore`。
- 已有作品陆续整理搬进来，整理好一个提交一个。
